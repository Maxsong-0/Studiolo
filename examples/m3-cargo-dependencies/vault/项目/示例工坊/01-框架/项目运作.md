# 示例工坊 · 项目运作

这是虚构项目的设计说明。表格不表示真实任务正在运行，目录核验也不证明功能已实现。

## 节点

| ID | 名称 | 类型 | 目录 | 职责 |
|---|---|---|---|---|
| reader | 资料使用者 | 外部 | - | 提出查询并阅读结果 |
| query | 检索接口 <示例> | 接口 | src/search | 接收条件，组织资料查询并返回结果 |
| catalog | 资料索引 | 模块 | src/catalog | 按分类整理可检索资料 |
| archive | 归档资料 | 数据 | src/archive | 保存旧资料；本示例目录刻意缺失 |
| export | 导出工具 | 模块 | tools | 生成可分享结果；该目录存在但未写入目录结构声明 |

## 关系

| 起点 | 终点 | 类型 | 说明 |
|---|---|---|---|
| reader | query | 依赖 | 使用检索入口 |
| query | catalog | 依赖 | 查询索引 |
| catalog | query | 数据流 | 返回分类结果 |
| catalog | archive | 数据流 | 读取历史资料 |
| catalog | catalog | 数据流 | 索引更新反馈（设计中的自环） |
| catalog | export | 数据流 | 提供结果摘要 |

## 任务路径

| 流程ID | 流程名称 | 步骤 | 节点ID | 说明 |
|---|---|---|---|---|
| search | 查询资料 | 1 | reader | 提出查询条件 |
| search | 查询资料 | 2 | query | 校验输入并发起索引查询 |
| search | 查询资料 | 3 | catalog | 查找分类与关联资料 |
| search | 查询资料 | 4 | query | 整理结果并返回 |
| search | 查询资料 | 5 | reader | 阅读结果并决定是否继续 |
| history | 查询归档 | 1 | query | 接收历史资料查询 |
| history | 查询归档 | 2 | catalog | 定位资料分类 |
| history | 查询归档 | 3 | archive | 读取归档；目录当前缺失，需要介入核对 |
| history | 查询归档 | 4 | query | 返回设计中的查询结果 |
