# 目录结构

## 代码仓库

仅声明根与 src 层；没有展开的深层目录不参与未文档化比较。

```text
repository/
├── src/                    # 资料索引与只读查询
│   ├── catalog/            # 中文资料的分类与索引，标签 <示例> 按原文显示
│   ├── search/             # 接收查询并返回对应的资料位置
│   └── archive/            # 旧资料归档（本示例刻意缺失，用于检查文档漂移）
└── docs/                   # 使用说明与约定
```

这些是文档中的职责声明，目录存在不代表功能已实现。
