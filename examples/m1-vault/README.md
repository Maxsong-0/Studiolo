# M1 虚构示例库

这些项目和动作均为人工测试夹具，不代表用户项目的实时状态。
仅供本机只读工作台与浏览器验收；没有真实笔记或凭据。

第二片验收：搜索“连续阅读”，切换“纸页”项目收窄结果；快速切换输入
“纸页 框架 阅读”。打开阅读体验后，可查看标题跳转、反链、同名配色方案选择，
以及缺页/缺标题提示。代码块中的伪链接与脚本样例都只能作为文本存在。

文件树验收：文档 → 文件树 → 附件演示，可展开空目录与仅附件目录。
CSV、Canvas、HTML 都只展示文件信息，不读取或预览附件内容；HTML 中的脚本不会执行。
空目录里的隐藏 `.gitkeep` 仅用于让 Git 保留夹具目录，不作为可见树节点。
