One chat, many heads.

Hydra is on from your first chat. The lead writes the briefs, sends heads out in parallel, each in a copy of your project, checks their work when they report back and lands it as one merge.

Meet Hydra.

The lead sends out Hank, Walter, Ada and the rest, hears back from each one as a badge in the chat, and keeps the team's panel at hand. Plans and questions come to you the same way, with a wave along the top when they wait on you.

Pair a strong lead with quick heads.

A pair says which model leads and which model, or which provider, runs the heads: a Claude lead over Gemini or OpenCode heads, picked straight from the model picker. Without a pair the heads take the chat's model at a working effort, so a Max lead sends out medium heads.

Effort, fused.

In a pair the slider is the lead's: its track blends the lead's colour into the heads', and says what effort the heads run at.

Panels that snap.

The team's panel, every head popped out of it and the usage panel dock to slots beside the chat, three a side on a 16-inch display, fewer on a smaller one. Drag one to any slot to reorder or swap, and let heads pop out on their own while there is room.

Droppy Code is the coding app by Droppy: a native macOS app that drives the coding agents you already have installed. It gives Codex, Claude, Cursor, OpenCode, Grok, Antigravity, Copilot, Command Code, Pi, DeepSeek, Meta and Z.ai one shared window with projects, threads, streaming replies, approvals, diffs, git and a terminal. It is made by the same people as Droppy for Mac.

Yes. Droppy Code is free and open source under the GNU AGPL v3.0, with one ask: whoever builds on it keeps the source open under the same license and keeps the credit to Droppy Code. You pay your agent providers as you already do; Droppy Code never sits in between, never proxies a request and never adds a markup.

Yes, all of it. The app lives on GitLab, written in Swift and SwiftUI, with every release and its notes on the releases page. Read it, build it in Xcode, or send a merge request. The code is AGPL-3.0, so forks stay open and keep the credit; the Droppy name and icon are not part of the license, as the trademark policy explains.

Not for Codex, Claude, Cursor, OpenCode, Grok, Antigravity, Copilot, Command Code or Pi: sign in once in your terminal, for example codex login, claude auth login, cmd login or pi then /login, and Droppy Code uses that session and your subscription. DeepSeek, Meta and Z.ai talk to their APIs directly, so those three take a key, stored in your Keychain.

A Mac with Apple silicon running macOS 26 or later. The app is built on Liquid Glass and ships as an Apple silicon binary only. It is signed with a Developer ID and notarized, so it opens without any Gatekeeper workaround.

Only what your agents send to their own providers. Droppy Code has no telemetry, no analytics, no account and no cloud sync. Remote access, mobile apps and a web client are left out on purpose. Your threads, checkpoints and settings stay on your Mac.

Droppy is the supercharged Dynamic Island for Mac. Droppy Code is its coding sibling, built by the same developer with the same taste for native Mac apps. They are separate apps: you do not need one to use the other, and Droppy Code does not need a Droppy license.

After every turn Droppy Code records a hidden git checkpoint of your project, so each reply comes with a diff and a revert button, and a thread can be rewound to any earlier turn. A new thread can also start in its own git worktree, a separate copy of the repository on its own branch, so several agents can work on one project at the same time without touching each other's files.
