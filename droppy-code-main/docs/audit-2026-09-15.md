# Droppy Code audit, 15 September 2026

A read of the whole app (99 Swift files, ~36k lines) plus measurements on this Mac: the real
library (47 threads, 2 projects, 31 heads), the attachment folder, the checkout's git
objects and the provider CLIs. Findings are grouped by area and ranked P0 (fix now) to P3
(nice to have). The ones marked **fixed** are in this branch; everything else is a
recommendation with the file and line it points at.

## P0: the checkout did not build

`DroppyCode/Views/Chat/ChatView.swift` in the lead's checkout held three unresolved
three-way merge hunks (`<<<<<<< ours` … `>>>>>>> theirs` at the old lines 160, 206 and 247),
left behind when a head's landing (`Git.apply` with `--3way`) could not settle the panel
refactor against the checkout. The "ours" side referenced `origin`, `panelDrag` and
`layout.panelHeight`, none of which exist any more; the "theirs" side is the `PlacedPanel`
call the rest of the file already uses. **Fixed**: the three hunks resolve to the
`PlacedPanel` version. A Debug build then succeeds with no new warnings.

This is also the clearest example of the Hydra landing hazard in the next section: the
markers sat in a file nobody was told to look at, and with "Merge when the team is done" on
they would have been committed and pushed.

### The auto-merge itself

The first attempt to land this pass failed live: a file the lead had written outside the
checkout was among a turn's touched paths, and `git add -A -- <path>` refused it. The
same attempt would also have taken only the lead's own five files, because a native head's
edits arrive as agent events and were never part of the lead's touched paths. Fixed: paths
outside the repository never enter `touchedPaths` (`TouchedPaths.relative`); a native head's
reported edits and the tree diffs around its writing commands are folded into the lead's
turn (`hydraTouched`); the merge counts only turns not yet merged (`TurnRecord.hydraMerged`)
and unions the heads' own reported edits plus everything changed since the job's first
checkpoint that was not already dirty before it. For this job that is 56 files, not 5.
