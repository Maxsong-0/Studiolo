# T-041 项目运作图首片与目录漂移

本片承接 T-039 指定的下一开发项，复用现有只读工作台与 WorkbenchReadModel，提供目录、
文档声明的模块职责、来源行和双向目录漂移。目录存在不能证明功能实现或部署。
完整图 2 的依赖、数据流及一次任务全链路仍待后续；本片不渲染人写 Mermaid/SVG。

## 显式绑定与读取范围

在仓库根目录构建后运行[虚构示例](../../examples/m3-project-operations/README.md)：

```bash
npm --prefix web run build
cargo run --locked -p studiolo-local-server -- \
  --vault examples/m3-project-operations/vault --assets web/dist --port 4324 \
  --project-repository "项目/示例工坊=$PWD/examples/m3-project-operations/repository"
```

CLI 每实例最多一个绑定，只允许本机或既有 Access 只读模式；会话、canonical 和因子
模式拒绝该参数，避免绕过既有 Auth/Audit/服务根隔离。未绑定项目显示未核验，
不会自动查找仓库。真实生产仓库挂载、资料同步和 AI 供给范围未在本片扩大。

绑定使用既有 `ReadOnlyVault` 固定根句柄；监听前及每次观测前后重新打开配置路径
比较目录身份，替换后失败关闭。只枚举非隐藏直属目录和普通文件元信息，不读源码
正文。隐藏项不进入结果但计入枚举预算；链接、特殊节点、硬链接、非规范名称和
名称碰撞拒绝完整观测。普通文件没有读取、预览或下载入口。

## 声明来源与比较范围

只识别当前索引中 `项目/<名称>/01-框架/目录结构.md` 的明确二级“代码仓库”章节，
标题可带空格或括号说明；提取该节首个完整 `text` 围栏。档案树、服务器树、其他
围栏和 HTML 注释中的示例不混入。仓库根为单个可见目录名加 `/`，后续使用标准
`├── `、`└── ` 和四字符缩进；目录以 `/` 结尾，` #` 后是原文职责。

目录节点保留路径、职责和一基行号。多段路径补隐含父目录，隐含节点没有人工职责
或来源。普通文件自身不画入图，明确文件路径只用于补隐含父目录。隐藏文件声明
忽略；可见省略、分组、通配、越界、非法缩进或冲突声明使整块不可用，不能静默
跳过后报通过。缺声明显示不可用；错误声明保留原因与原文入口。

比较只覆盖声明实际展开的父目录层级，不递归核对未展开的叶目录。例如 `src/`
下列出 `model/`，则比较 `src` 的直属目录；`model/` 未展开时内部目录不进入检查。
普通文件的多段父路径不隐式要求其每层完整列举。

| 状态 | 含义 |
|---|---|
| `present` | 当前观测确认声明目录存在，不表示能力已实现 |
| `missing` | 完整观测确认声明目录或其祖先缺失 |
| `undocumented` | 已比较父层中存在文档未声明的目录 |
| `unverified` | 未绑定、缺观测、失败或证据矛盾，不能下结论 |

不猜测重命名，新增与删除分别显示。源码根中的生成目录如果位于比较父层，也会
显示未文档化，本片不猜测忽略规则。界面展示明确的比较父域。

## 查询与一致性

`GET /api/project-operations?project=项目/名称&generation=N` 复用逐请求来源、Access、
应用会话门禁及查询信号量。计算在阻塞线程执行，取消请求不提前释放许可。
未知或重复参数拒绝；宿主路径不能作为请求参数。响应只含逻辑路径。

响应包括文档 `generation`、声明与比较父域、仓库 `status`/`observed_at` 和 `drift`。
`observed_at` 是观测完成时 Unix 秒十进制字符串；未绑定或失败为 null。
`repository.status=ready` 仅表示本批观测完成，不等于无漂移或已上线。

文档来自不可变索引，旧 generation 返回 409。每次查询重新枚举仓库，要求两轮
完整结果相同且固定根身份相同；不以旧目录缓存替代当前证据。任一父层失败、预算
溢出或两轮不同则整批未核验，不返回部分实际路径。子节点枚举中的 NotFound 不得
当成父目录缺失。两轮相同不构成文件系统事务，也不承诺跨根原子快照；界面分别
显示文档代次和仓库观测时间。修改声明须刷新工作台，修改目录可重新核验。

声明块最多 64 KiB、256 个目录和 64 个比较父层；多段路径在逐段扩展时即检查限额，
不先分配整条深路径的全部前缀。Broker 每父层最多 8192 条枚举项，
名称安全解析沿用现有每层 50,000 项上限。单轮观测合计最多 1024 个实际目录、
256 KiB 返回路径；超限均不可用。输出经 JSON/React 文本转义，图形失败回退纯文本。

与职责使用真实 DOM 自然排版，不按拉丁字宽猜坐标。窄屏只让图容器横滚，页面不
横滚；目录按钮可键盘操作，现有 reduced-motion 分支保留，没有自动播放。
