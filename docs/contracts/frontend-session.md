# 浏览器会话入口（T-021）

## 入口和授权

实际生产入口由 `SessionBoundary` 包住工作台。首先请求
`GET /api/v1/bootstrap`，仅接受严格对象 `{ "authentication": "local|access|session" }`。
响应只说明可信组合根选择的模式，不含身份、Cookie、CSRF、配置或秘密。
所有模式禁止查询参数和非 GET；Access 模式仍逐请求验签，会话模式仍核浏览器同源头。
bootstrap 不依赖应用 Cookie 或 AuthDB，因此数据库故障也能明确声明会话模式。

只有明确的 local/access 才打开原读取界面。session 模式先 GET 自身，401 后显示登录；
用户点击才 POST 空对象签发，成功后显示工作台和账户入口。未知模式、额外字段、
404、Access 401、503、网络错误均关闭内容，不以接口缺失推断旧模式。

## 浏览器状态

- CSRF 仅在内存；Cookie 仍由浏览器保管。所有 API 请求统一 same-origin 凭据、
  no-store、禁止重定向及固定自定义头；POST 才带明确 JSON 和需要的 CSRF。
- 授权变化递增本地请求代次并取消请求，拒绝旧响应；工作台连同原文弹层卸载，
  不继续展示上一个会话的内容。服务端仍对每个请求重新授权。
- 当前、指定和全部会话退出均显式操作。指定其他会话成功后重新读取列表；
  当前/全部操作开始即清内容。错误 OTP 等后续因子行为不在本片内。
- POST 网络错误、503 或中断可能已提交，显示不确定状态并只提供显式 GET 核对；
  不自动重放登录或退出。401 清内容；503 不自行清除可能有效的 HttpOnly Cookie。
- BroadcastChannel 广播只含变化通知；不支持时通过 localStorage 非秘密随机标记通知。
  页面隐藏取消内容，焦点/页面恢复/跨标签变化重新核对。绝对期限计时仅作 GET 提示，
  最小 30 秒间隔防客户端时钟偏差导致循环；授权期限由服务器决定。

## 验证边界

自动测试覆盖严格模式、延迟响应、StrictMode、401 清原文、503 不重放、
当前/指定/全部退出、跨标签回退与恢复焦点；生产浏览器验证结果记录在 M2 检查点。
虚构 HTTP 会话夹具验证界面和真实浏览器事件，不证明 Access 登录、Secure Cookie、
真实身份、手机或公网故障恢复。当前片不开放 TOTP/恢复码界面或 canonical 编辑。
