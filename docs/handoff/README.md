# handoff/ — 给读不到 vault 的会话的交接快照

项目档案（任务协调、计划、ADR、日志）的权威在用户的 Obsidian vault `项目/Studiolo/`，只在用户的 Mac 上。
Cursor Cloud 这类云端会话读不到它，所以把**当前在推进的工作**所需的文档快照放在这里（用户 2026-09-28 指示）。

## 规矩

- **vault 为准**：这里是快照，可能滞后；每份文件开头写了同步来源与日期。本机会话改了 vault 原件，要同步刷新这里。
- **只放在推进中的工作**：收尾归档后删掉对应快照（vault 里有完整留档），别让这里变成第二份档案库。
- **不放凭据**：真实密钥、口令、token 永不进仓库，也不进这里。
- vault 的 `[[wiki链接]]` 已改写：同步过来的文件互相用相对链接，没同步的写成「名称」（vault，未同步）。

## 云端会话怎么干活

- 验证一律用 **GitHub CI**：推分支／开 PR 触发自托管 runner（`AGENTS.md` 第五节）；推之前在 VM 里用 `scripts/test-cursor-cloud.sh` 与 `npm --prefix web run …` 把能验的验完（`AGENTS.md` 第六节）。
- 需要登录内网机器（107／108／169）、读写 vault、或用 studiolo MCP 的步骤，云端做不了——停下，在回复或 PR 描述里写明「交本机会话」，不要索要或注入内网／SSH 凭据。
